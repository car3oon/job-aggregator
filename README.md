# Job Aggregator 🎯

A personal, automated job offer aggregator built with Next.js. It fetches job listings from various portals and categorizes them into dedicated, easy-to-browse views (e.g., React, Vue.js, Remote, Office). 

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + shadcn/ui (Light Violet Theme)
- **Database:** (Planned) Relational database (Vercel Postgres / Supabase)
- **Security:** Custom Basic Auth via Next.js Middleware

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
